# Swipe Clean

Tinder-style file cleaner for your Android **Downloads** folder (and any other folder you grant access to).

### Features
- Swipe (or tap buttons) left to send to trash, right to keep
- Large preview / thumbnail for photos and videos
- Generic file-type icons for documents, APKs, archives, etc.
- Live counter of current item + remaining items to review
- Trash review screen — review everything marked for deletion before permanently deleting
- Quick storage awareness (shows free space)

Built as a focused MVP matching the original request.

## How to use
1. Open the app
2. Grant access to your Downloads folder (or pick any folder)
3. Swipe through the files
4. When finished, go to Trash and confirm permanent delete

## Build & Install
Use the included GitHub Actions workflow to produce a debug APK, or open the project in Android Studio.

**Requirements:** Android 8.0+ (API 26)
